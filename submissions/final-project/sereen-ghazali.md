## Project Description

DevCommunity is a full-stack developer community platform built with Next.js, MongoDB, Mongoose, Auth.js, and Tailwind CSS. It allows developers to explore and join communities, create and manage blog posts, interact through comments and bookmarks, and manage their developer profiles.

## Completed Requirements

- GitHub and Google authentication
- Developer profiles
- Community browsing and membership
- Blog creation, editing, and deletion
- Blog detail pages
- Comments and comment deletion
- Bookmarking
- Protected dashboard and settings
- Search and filtering
- Sorting and pagination
- Server-side authorization and ownership checks
- Zod validation
- MongoDB Atlas integration
- Loading, error, and not-found states
- Production deployment on Vercel
