# Final Project Submissions

This folder contains registered student submissions for the Final Project.

The complete final project brief is available in the official TechTalks Google Drive.

## Before Submitting

You must:

1. Create the final project in your own GitHub repository.
2. Push the initial project to main.
3. Create a final project branch.
4. Complete the work on that branch.
5. Open a pull request from the final project branch into main.
6. Keep that pull request open for mentor review.
7. Deploy the project on Vercel.

## Submit Your Final Project

Create one Markdown file using your full name:

```
firstname-lastname.md
```

Example:

```
ali-jichi.md
```

Your submission must include:

- Full name
- GitHub username
- Project repository URL
- Code review pull request URL
- Live deployment URL
- Submission date
- Project description
- Completed requirements
- Known issues

Your repository must follow the required naming format:

```
techtalks-final-project-firstname-lastname
```

Your branch must follow the required naming format:

```
final-project-firstname-lastname
```

Do not upload your full Next.js project to this folder.
