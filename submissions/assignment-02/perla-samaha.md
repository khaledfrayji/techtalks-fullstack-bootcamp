## Project Description
This project is a market research and career roadmap deliverable for the Full-Stack Developer niche. 
I researched 8 real, currently-active full-stack developer job listings across three regions — Lebanon, Dubai (UAE), and the United States (remote) — and analyzed them to identify which skills employers ask for most often. 
The research showed React and Node.js as the consistent core skill set across all three regions, with AWS as the most common cloud requirement, while secondary tooling (Java/Spring/Angular vs. Next.js/MERN) varied by region and employer type (enterprise/government vs. startup/product). 
Based on this evidence, I built a six-month, month-by-month learning roadmap prioritizing React, TypeScript, Node.js, SQL, Docker/cloud basics, and testing, plus a three-project portfolio plan designed to demonstrate the specific skills that repeated across the researched listings.
