# Code of Conduct

## Our Standards

All participants in the TechTalks Full-Stack Bootcamp are expected to maintain a professional and respectful environment. The following standards apply to all interactions in this repository, including pull requests, issues, comments, and code reviews.

### Expected Behavior

- Communicate respectfully and professionally at all times.
- Provide constructive and specific feedback during code reviews.
- Accept feedback graciously and use it to improve your work.
- Acknowledge and credit the work of others where appropriate.
- Ask questions clearly and provide enough context for others to help.

### Unacceptable Behavior

- Harassment, insults, or personal attacks of any kind.
- Plagiarism or submitting another student's work as your own.
- Editing, deleting, or altering another student's submission files.
- Posting spam, irrelevant content, or repeated identical comments.
- Sharing private information such as passwords, API keys, tokens, or personal data.
- Unprofessional behavior during code reviews or discussions.

## Academic Integrity

Students must submit only their own original work. Copying code from other students without proper understanding or attribution is not permitted. TechTalks mentors reserve the right to verify that a student can explain the code they submitted.

## Enforcement

TechTalks may remove content, close pull requests, or restrict participation for any violation of this Code of Conduct. Repeated or serious violations may result in removal from the program.

## Reporting

If you observe behavior that violates this Code of Conduct, please report it through the appropriate TechTalks communication channels.
