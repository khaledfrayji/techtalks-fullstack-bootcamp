## Project Description

DevCommunity is a full-stack platform where developers can join communities, publish technical articles, comment on posts, bookmark articles, and manage their developer profiles. It was built using Next.js, TypeScript, Tailwind CSS, MongoDB, Mongoose, Auth.js, and Zod.

## Additional Notes

The application supports Google and GitHub authentication, protected routes, article CRUD operations, ownership authorization, comments, bookmarks, communities, search, filtering, pagination, and a personalized dashboard.
