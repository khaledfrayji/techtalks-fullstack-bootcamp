## Project Description

**MUG Coders** is a full-stack developer community platform built using Next.js 16, React, TypeScript, Tailwind CSS, MongoDB Atlas, Mongoose, Auth.js, and Zod.

The platform supports developer profiles, communities, technical discussions, blog CRUD operations, comments, bookmarks, search, filtering, pagination, and Google/GitHub authentication.

The application includes five customizable visual themes and is deployed on Vercel.
