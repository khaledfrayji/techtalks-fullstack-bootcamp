# Project Description
A Next.js 16 App Router project for a Developer Community Platform, where developers can browse communities, view posts, explore topics, and visit developer profiles.

# Completed Requirements
- Pages: /, /about, /communities, /topics, /developers
- Nested routes under /communities (web-development, mobile-development, ui-ux)
- Nested routes under /developers (top-rated, new-members)
- Dynamic routes: /communities/[slug], /developers/[username], /developers/[username]/posts/[postId]
- Route group used to organize main pages
- Shared Navbar/Footer layout
- Server Component for static data rendering
- Client Component: JoinButton (interactive)
- Local static data files for communities, developers, and posts
