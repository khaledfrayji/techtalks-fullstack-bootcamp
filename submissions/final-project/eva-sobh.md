\## Project Description



DevCommunity is a full-stack developer community platform built with Next.js App Router, MongoDB Atlas, Mongoose, Auth.js, Zod, and Tailwind CSS.



The platform allows developers to discover and join communities, create and manage technical blog posts, search and filter content, build public developer profiles, comment on posts, and bookmark useful content.



The project includes GitHub and Google OAuth authentication, email/password credentials authentication, protected routes, server-side ownership and authorization checks, client and server-side Zod validation, search/filter/sort/pagination, responsive design, multiple rendering strategies, error and empty states, and production deployment through Vercel.
